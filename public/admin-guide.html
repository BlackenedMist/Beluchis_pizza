1. Logging in

Open /admin and sign in with your admin account (username + PIN). Cashiers use /cashier. Drivers use /driver.

2. Admin portal overview

Sidebar tabs: Orders, Users, Menu/Items, Specials, Toppings, Bases, Pasta Types, Categories, Printers, Shop (Delivery), Deliveries.

3. Orders queue

  • Orders appear newest first with status, items, total and payment method.
  • Paid-online orders show "Total R… · Paid online R…" instead of R0.00.
  • Status filter and date filter ("All days" available).
  • Change status as it progresses: placed → preparing → out for delivery → delivered. Cancel if needed.
  • New-order notifications fire only while an order is still being processed.

4. Menu management (step by step)

4.1 Adding a category

  1. Admin portal -> Menu -> Categories.
  2. Click + Add category.
  3. Enter name (e.g. "Pizzas") and optional deal badge text.
  4. Set sort order, then Save.

4.2 Adding an item

  1. Go to Menu -> Items -> + Add item.
  2. Fill in name, description, slug, category.
  3. Upload an image (stored under /uploads).
  4. Add sizes: click + Size, enter label and price for each.
  5. Toggle Active and Show on home.
  6. Save.

4.3 Editing / deactivating

  1. Find the item (use search box).
  2. Click Edit, change fields, Save.
  3. To hide temporarily, toggle Active off.

4.4 Custom items (bases & extra toppings)

  1. Open an item -> Customise section.
  2. Bases: add each base option with per-size price (0 for default).
  3. Extra toppings: add each topping with per-size price.
  4. For seasonal items, tick "out of season" - customers get a free swap for an in-season topping of the same value.
  5. Save.

4.5 Images

  • Upload JPG/PNG. Recommended: square, at least 600x600 px.
  • First image = thumbnail; multiple images = gallery in the customiser.

4.6 Pasta types

  1. Go to Menu -> Pasta Types -> + Add pasta type (e.g. Spaghetti, Penne, Linguine).
  2. Set any extra charge per size - leave at 0 if the type has no surcharge.
  3. Tick Assign to every item in the Pastas category to link the type to all pasta items at once, then Save.
  4. To fine-tune an individual dish, open it under Menu -> Items and tick the Pasta types it should offer.
  5. Customers then see a Pasta type picker when adding that pasta; the extra charge is added to the line and printed on the ticket as Pasta: Penne.
  6. Untick Active on a type to hide it everywhere without deleting it.

5. Specials (deals) - step by step

5.1 Creating a special

  1. Open Menu -> Specials -> + Add Special.
  2. The accordion form opens. Expand each section by clicking its header.

5.2 Section 1 - The offer

  1. Enter a Name (shown on the card, e.g. "Buy 3 Deluxe, get 1 free").
  2. Choose the Offer type:
    • Buy X, get Y free - the customer picks from a category or from specific items.
    • Any N for a set price - an automatic deal (e.g. any 2 Large for R200).
    • Combo of items at a set price - a fixed combo.
    • One item at a reduced price - e.g. Pizza of the Month.
    • Build-your-own bundle - the customer chooses per group.
  3. Set Status (Active/Inactive) and Sort order.

5.3 Section 2 - What the customer gets

  1. For buy-X-get-Y and automatic deals, choose the Category and an optional Size.
  2. For buy-X-get-Y, enter Customer pays for and ...and gets free. Example: pays for 3, gets 1 free = the customer picks 4 and the cheapest 1 is free.
  3. For curated offers, tick the Items in the offer and set the size for each.
  4. For reduced-price offers, tick exactly one item.
  5. Bundles use the advanced Bundle groups (JSON) box; one group per course.

5.4 Section 3 - Home page and order page

  1. Tick Show on home, then choose Tile or Full-width banner.
  2. Tick Collection only for an offer that may only be used on collection orders. It still advertises with a badge, but delivery customers cannot add it at checkout.
  3. Add an optional Badge (e.g. "SAVE R89").
  4. Open Custom wording to override the auto-generated Headline, Supporting line and Price label.
  5. Check the Live preview - it shows the tile and banner exactly as customers will see them.
  6. If no picture is uploaded, the tile/banner cycles through the photos of the dishes in the offer.

5.5 Section 4 - Description, picture and schedule

  1. Add a short Description for the menu card (optional).
  2. Upload a Picture if you have one (otherwise the dish photos rotate).
  3. Tick the days the special is active (Mon-Sun).
  4. Optionally set a start date and end date for a limited run.
  5. Leave both empty for an always-on special. Only specials active on the current day appear on the storefront.

5.6 Section 5 - Social

Prerequisite for "Post to Facebook": go to Shop -> Social, add the Facebook Page ID and Page Access Token (or use Connect with Facebook), then click Test connection to verify. Save the social settings.

  1. Tick Post to Facebook to publish on save.
  2. Save special.

5.7 Editing / deleting

  1. Click a special -> Edit -> change -> Save special.
  2. Click Schedule to change weekdays and start/end dates without opening the full form.
  3. Click Delete to remove (confirms first).
  4. The list tags collection-only offers so staff can see them at a glance.

5.8 Quick Promotions (simplified)

At the top of the Specials tab there are quick buttons that create common promotions with minimal input:

  • Pizza of the Month - pick one pizza, size, reduced price, and the month dates. Published on home by default.
  • Fixed Bundle - add items one by one (name + size) and set a single bundle price.
  • Selection Bundle - add items and mark which are paid (customer pays for those) and which are free.
  • Range Bundle - build paid/free groups by category, optionally restrict to specific items, and choose pricing (item value or fixed price).

Each quick promotion supports image upload and start/end dates.

5.9 Deals tab (automatic multi-buy)

  • Open Menu -> Deals. Each category shows price boxes per size.
  • Set Buy this many and the flat price for that size.
  • Tick weekdays for the deal (empty = every day).
  • Super Sunday Special and Weekday Special buttons create single-pizza discounts (count = 1) for selected days, categories and sizes.
  • Deals apply automatically in the cart; extras are always charged.

5.10 Images

Every special supports an image upload. Use the image field in the form or quick promotion, then Save. Images appear on the special card.

6. Printers

Tab Printers under Store. Each printer: name, type (network/file), host, port, copies per order, enabled, sort order.

  • Add / Edit / Delete — prompt-based quick editing.
  • Test — queues a test print; daemon prints a test slip.
  • Scan network — daemon scans local subnet for printers on port 9100.
  • Offline alert — red banner on admin and cashier when any printer is offline or a print failed.
  • Daemon polls this config on startup and every poll; auto-resolves a changed IP by scanning the subnet and updating the server.

6.1 Kitchen daemon auth password

At the top of the Printers tab there is a Kitchen daemon auth password field.

  1. Enter the password the daemon uses (its PRINT_KEY env var).
  2. Click Save key. Stored on the server and in your browser.
  3. Leave blank to disable auth (daemon must also have no PRINT_KEY set).
  4. The Scan network button sends this password to the daemon. If scans fail with 403, the password does not match the daemon's PRINT_KEY.

7. Shop settings

Tab Shop (Delivery):

  • Hours — open/close time, online orders toggle. Changes email the owner (if an alert email is set).
  • Open/closed — toggles the shop flag on the home page.
  • Delivery config — enable, shop location (lat/lng), free radius, fee, max radius, beyond fee, minimum order for free delivery.
  • Social — Facebook Page ID, Page Access Token, Instagram User ID, owner alert email.
  • Connect with Facebook — opens FB login dialog to obtain a token.
  • Test connection — verifies the Page ID + token against Facebook before you rely on "Post to Facebook".

8. Users

View customer accounts, reset passwords, view order counts.

9. Deliveries

Track deliveries, assign drivers, mark delivered.

10. Cashier page (/cashier)

  • Live order queue with the same filters.
  • New order alert — sound/notification when a new order arrives.
  • Printer offline banner — red warning if a printer is down.
  • Receipt reprint button per order.

11. Kitchen daemon (kitchen/)

Headless Node service (port 3101) that polls the server for new orders and prints receipts.

VariablePurpose
SOURCE_BASE_URLServer URL (default http://localhost:3100)
PRINT_KEYShared key for printer endpoints
POLL_SECONDSPoll interval (default 15)
AUTO_PRINTtrue/false (default true)
AUTO_MARK_PREPARINGtrue/false (default true)

Endpoints: /health, /api/print/:id, /api/scan?port=9100.

  • Polls orders; prints each new order on all enabled printers, respecting copies.
  • Auto-marks order as "preparing" after a successful print.
  • On print failure, scans the subnet to auto-resolve the printer IP and retries.
  • Reports heartbeat (per-printer status) to the server.

12. StandAlone bridge (StandAlone/)

Local bridge (port 3102) used when the kitchen PC is the print source. Stores printers locally in data/printers.json and syncs with the server. Local edits push to the server; server config overwrites local on poll.

13. Receipts

Kitchen and StandAlone receipts include:

  • Shop name, website, phone, VAT number.
  • Order number, type (delivery/collection), time, payment method.
  • Items with quantities and prices (free items show R0).
  • Customer, phone, delivery address.
  • Subtotal, discount, TOTAL AMOUNT, and for paid-online orders: "Paid online R…" + "No balance due".
  • VAT breakdown: Total Excl VAT / VAT Incl. (15%).

Sybalk-oortjies: Orders, Users, Menu/Items, Specials, Toppings, Bases, Pasta Types, Categories, Printers, Shop (Delivery), Deliveries.

3. Bestellingry

  • Bestellings verskyn nuutste eerste met status, items, totaal en betaalmetode.
  • Aanlyn-betaalde bestellings wys "Total R… · Paid online R…" in plaas van R0.00.
  • Statusfilter en datumfilter ("All days" beskikbaar).
  • Verander status soos dit vorder: placed → preparing → out for delivery → delivered. Kanselleer indien nodig.
  • Nuwe-bestelling-kennisgewings vuur slegs terwyl 'n bestelling nog verwerk word.

4. Spyskaartbestuur (stap vir stap)

4.1 Voeg 'n kategorie by

  1. Admin-portaal -> Menu -> Categories.
  2. Klik + Add category.
  3. Voer naam in en opsionele aanbod-teksmerker.
  4. Stel sorteerorde, dan Save.

4.2 Voeg 'n item by

  1. Gaan na Menu -> Items -> + Add item.
  2. Vul naam, beskrywing, slug, kategorie in.
  3. Laai 'n beeld op (onder /uploads).
  4. Voeg groottes by: klik + Size, voer etiket en prys in.
  5. Skakel Active en Show on home aan.
  6. Save.

4.3 Wysig / deaktiveer

  1. Vind die item (gebruik soekboks).
  2. Klik Edit, verander velde, Save.
  3. Om tydelik te versteek, skakel Active af.

4.4 Pasgemaakte items (basisse & ekstra toppings)

  1. Maak 'n item oop -> Customise-afdeling.
  2. Basisse: voeg elke basisopsie by met per-grootte prys (0 vir verstek).
  3. Ekstra toppings: voeg elke topping by met per-grootte prys.
  4. Vir seisoenale items, merk "out of season" - kliënte kry 'n gratis ruil vir 'n in-seisoen topping van dieselfde waarde.
  5. Save.

4.5 Beelde

  • Laai JPG/PNG op. Aanbeveel: vierkantig, minstens 600x600 px.
  • Eerste beeld = miniatuur; veelvuldige beelde = gallery in die aanpasser.

4.6 Pastatipes

  1. Gaan na Menu -> Pasta Types -> + Add pasta type (bv. Spaghetti, Penne, Linguine).
  2. Stel enige ekstra koste per grootte - los op 0 as die tipe geen toeslag het nie.
  3. Merk Assign to every item in the Pastas category om die tipe aan alle pasta-items gelyk te koppel, dan Save.
  4. Om 'n spesifieke gereg fyn te stel, maak dit oop onder Menu -> Items en merk die Pasta types wat dit moet bied.
  5. Kliënte sien dan 'n Pasta type-keuse wanneer hulle daardie pasta byvoeg; die ekstra koste word by die lyn gevoeg en as Pasta: Penne gedruk.
  6. Merk Active af op 'n tipe om dit oral te versteek sonder om dit te verwyder.

5. Spesiale (aanbiedinge) - stap vir stap

5.1 Skep 'n spesiale

  1. Maak Menu -> Specials oop -> + Add Special.
  2. Die akkordeonvorm open. Vou elke afdeling uit deur op die kop te klik.

5.2 Afdeling 1 - Die aanbod

  1. Voer 'n Naam in (wys op die kaart, bv. "Koop 3 Deluxe, kry 1 gratis").
  2. Kies die Aanbodtipe:
    • Koop X, kry Y gratis - die kliënt kies uit 'n kategorie of spesifieke items.
    • Enige N vir 'n vaste prys - 'n outomatiese deal (bv. enige 2 Groot vir R200).
    • Kombinasie teen 'n vaste prys - 'n vaste kombinasie.
    • Een item teen 'n verlaagde prys - bv. Pizza van die Maand.
    • Bou-jou-eie-bundel - die kliënt kies per groep.
  3. Stel Status (Aktief/Onaktief) en Sorteervolgorde.

5.3 Afdeling 2 - Wat die kliënt kry

  1. Vir koop-X-kry-Y en outomatiese deals, kies die Kategorie en 'n opsionele Grootte.
  2. Vir koop-X-kry-Y, voer Kliënt betaal vir en ...en kry gratis in. Voorbeeld: betaal vir 3, kry 1 gratis = die kliënt kies 4 en die goedkoopste 1 is gratis.
  3. Vir gekureerde aanbiedinge, merk die Items in die aanbod en stel die grootte vir elkeen.
  4. Vir verlaagde-prys aanbiedinge, merk presies een item.
  5. Bundels gebruik die gevorderde Bundle groups (JSON)-blokkie; een groep per gang.

5.4 Afdeling 3 - Tuisblad en bestelblad

  1. Merk Show on home en kies Tile of Volle-wydte banner.
  2. Merk Collection only vir 'n aanbod wat slegs op afhaalbestellings gebruik mag word. Dit adverteer steeds met 'n badge, maar afleweringskliënte kan dit nie byvoeg nie.
  3. Voeg 'n opsionele Badge by (bv. "SPAAR R89").
  4. Maak Custom wording oop om die outomatiese Opskrif, Ondersteunende lyn en Prys-etiket te oorskryf.
  5. Kyk na die Live preview - dit wys die teël en banner presies soos kliënte dit sal sien.
  6. As geen prent opgelaai is nie, wissel die teël/banner deur die foto's van die geregte in die aanbod.

5.5 Afdeling 4 - Beskrywing, prent en skedule

  1. Voeg 'n kort Beskrywing vir die spyskaartkaart by (opsioneel).
  2. Laai 'n Prent op as jy een het (anders roteer die geregfoto's).
  3. Merk die dae waarop die spesiale aktief is (Ma-So).
  4. Stel opsioneel 'n begin- en einddatum vir 'n beperkte lopie.
  5. Laat albei leeg vir 'n altyd-aan spesiale. Slegs spesiale wat op die huidige dag aktief is, verskyn op die voorkant.

5.6 Afdeling 5 - Sosiaal

Voorvereiste vir "Post to Facebook": gaan na Shop -> Social, voeg die Facebook Bladsy-ID en Bladsy-toegangstoken by (of gebruik Connect with Facebook), klik dan Test connection om te verifieer. Stoor die sosiale instellings.

  1. Merk Post to Facebook om by stoor te publiseer.
  2. Save special.

5.7 Wysig / verwyder

  • Klik 'n spesiale -> Edit -> verander -> Save special.
  • Klik Schedule om weekdae en datums te verander sonder die volle vorm.
  • Klik Delete om te verwyder (bevestig eers).
  • Die lys merk collection-only aanbiedinge sodat personeel dit dadelik sien.

6. Drukkers

Oortjie Printers onder Store. Elke drukker: naam, tipe (netwerk/lêer), gasheer, poort, kopieë per bestelling, geaktiveer, sorteerorde.

  • Add / Edit / Delete — vinnige redigering via boodskappe.
  • Test — plaas 'n toetsdruk in die tou; daemon druk 'n toetsstrook.
  • Scan network — daemon skandeer plaaslike subnet vir drukkers op poort 9100.
  • Vanlyn-waarskuwing — rooi baniere op admin en kassier wanneer enige drukker vanlyn is of 'n druk misluk het.
  • Daemon peil hierdie konfig by opstart en elke peiling; los 'n veranderde IP outomaties op.

6.1 Kombuis-daemon auth-wagwoord

Boaan die Printers-oortjie is 'n Kitchen daemon auth password-veld.

  1. Voer die wagwoord in wat die daemon gebruik (sy PRINT_KEY-omgewingsveranderlike).
  2. Klik Save key. Die waarde word op die bediener en in jou blaaier gestoor.
  3. Laat leeg om auth te deaktiveer (daemon moet ook geen PRINT_KEY gestel hê).
  4. Die Scan network-knoppie stuur hierdie wagwoord na die daemon. As skanderings met 403 misluk, stem die wagwoord nie ooreen met die daemon se PRINT_KEY nie.

7. Winkelinstellings

Oortjie Shop (Delivery):

  • Ure — oop/sluit tyd, aanlyn bestellings skakelaar. Veranderinge e-pos die eienaar (as waarskuwings-e-pos gestel is).
  • Oop/gesluit — skakel die winkelvlag op die tuisblad.
  • Afleweringskonfig — aktiveer, winkel-ligging (lat/lng), gratis radius, fooi, maksimum radius, verder-fooi, minimum bestelling vir gratis aflewering.
  • Sosiaal — Facebook Bladsy-ID, Bladsy-toegangstoken, Instagram Gebruiker-ID, eienaar-waarskuwings-e-pos.
  • Connect with Facebook — open FB-inteken-dialoog om 'n token te verkry.
  • Test connection — verifieer die Bladsy-ID + token teen Facebook voordat jy op "Post to Facebook" staatmaak.

13. Strokies

Kombuis- en StandAlone-strokies sluit in:

  • Winkelnaam, webwerf, telefoon, BTW-nommer.
  • Bestellingsnommer, tipe (aflewering/afhaal), tyd, betaalmetode.
